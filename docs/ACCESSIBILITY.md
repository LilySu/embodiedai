# Accessibility

Embodied Coffee targets WCAG AAA where practical.

## Product Rules

- No swipe-only actions.
- Touch targets at least 48 by 48 CSS pixels.
- Dynamic type support up to 2x.
- Plain-language labels.
- High contrast text and controls.
- VoiceOver and TalkBack walkthrough before alpha.

## CI Targets

- React Native accessibility checks.
- Focus-order checks on web.
- Screen reader smoke tests for onboarding, matching, messaging, and settings.
